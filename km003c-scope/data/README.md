# USB IDs Snapshot

`usb.ids` is a vendored snapshot of the USB ID database used to resolve USB-IF
vendor IDs observed in USB Power Delivery Discover Identity messages.

- Source: <https://github.com/vcrhonek/hwdata/blob/master/usb.ids>
- Canonical project: <http://www.linux-usb.org/usb-ids.html>
- Database version: `2026.06.26`
- Database date: `2026-06-26 20:34:02`
- SHA-256: `34B2B2289508A866CF38B96E54B37AC52C0AB7CE8361A56116AF24E3FD094421`
- License: see `usb.ids.LICENSE`

The scope build extracts only top-level vendor records. Product and class
records in the snapshot are not embedded in the executable.
